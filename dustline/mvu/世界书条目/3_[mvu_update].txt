变量更新规则:
  _强制更新提醒:
    - 以下变量每次回复必须更新，不得遗漏:
    - 世界.当前时间 — 每次事件推进后更新
    - 世界.当前地点 — 场景移动后更新
    - 世界.${当前界域|当前国家|当前城市} — 跨界、跨国或进出城市时更新；天气、城市状态等随剧情合理刷新
    - 世界.危机程度 — 无/低/中/高/致命，驱动前端氛围
    - 世界.动向 — 每轮滚动维持1~8条与当前地点或当前剧情直接相关的事件，约一半客观世界、一半主角或当前行动，旧条目必须remove
    - 世界.政府动向 — 每轮滚动维持1~8条政府行动，旧条目必须remove
    - 世界.军事动向 — 每轮滚动维持1~8条军事部署、冲突与戒备，旧条目必须remove
    - 世界.国家动向 — 每轮滚动维持1~8条国家层面变化，旧条目必须remove
    - 世界.全球动向 — 每轮滚动维持1~8条跨国或全球变化，旧条目必须remove
    - 世界.世界局势 — 维护1~4条宏观局势主题；只有态势、参与方或影响发生变化时才更新
    - 讯息 — 每次安排讯息发送，如果发送者是NPC则必须与操作者有联系方式且检查当前环境是否接收到讯息；其他类型则发公共通知或者来源未知
    - 互联网 — 每次更新3~4个互联网事件，旧事件必须移除且需要检查当前环境是否可以接收到互联网消息
    - 以下变量在发生对应事件时必须更新:
    - 世界.当前篇章 — 控制篇章世界书注入，默认地球篇；只有真实跨篇章/跨世界时才更新
    - 世界.当前剧情线 — 控制剧情路线世界书注入，默认命定红瞳；只有开局选择或明确切换主线时才更新
    - 主角.${生命|精血|灵力|神识} — 战斗、受伤、消耗、恢复时
    - 主角.修为 — 修炼、服丹、顿悟时
    - 命轨 — 隐藏条件满足时记录即将执行的剧情节点
    - 主角.道心 — 抉择、背叛、坚守、悟道时
    - 主角.储物袋 — 获取、使用、交易物品时
    - 主角.功法 — 获取、修炼功法时
    - 主角.器物 — 获得、使用、受损或修复器物时
    - 主角.资产 — 收入、支出、交易、投资、被夺或资产损毁时
    - 主角.社会地位 — 声望、风评、名号、头衔或污点发生变化时
    - 主角.衣着 — 开局写入、换装、湿损、破损或褪去时逐项刷新
    - 主角.身体状态 — 受伤、出汗、沐浴、天气剧变或亲密接触时刷新对应部位
    - 主角.异常状态 — 中毒、失忆、封印、心智异变等结构化异常新增、加深、消退或解除时
    - 主角.${炼丹|炼器} — 进行炼制行为时更新熟练度、成功率与次数
    - 女性/男性角色档案 — 长线剧情推进、背景事实改变时同步
    - 当前在场互动女性/男性 — 与角色互动时更新身心状态、好感、衣着等动态细节
    - 角色追踪事件 — 正文明确描写内射终结动作时新增或累加
    - 所处势力 — 主角加入、退出、晋升或势力状态、人数、动向、关键人物发生变化时更新
    - 羁绊 — 与任意人物形成或改变稳定关系时更新；只有羁绊中的人物允许记录心声
    - 灵宠 — 与灵宠互动或参战时更新状态、亲密度
    - 任务 — 接受目标、推进阶段、完成、失败或放弃任务时更新；严禁把尚未接受的机会直接写成任务
  _禁止更新:
    - 以 `_` 开头的字段为只读，禁止更新，例如 `_变量`、`主角.资产._股市`

  世界:
    当前篇章:
      format: "地球篇/灵域篇/其他自定义篇章名"
      check:
        - 当前篇章用于驱动世界书注入控制器，默认保持地球篇
        - 只有剧情真实进入新篇章或新世界时才允许更新，禁止因为临时提及其他世界而改动
    当前剧情线:
      format: "命定红瞳/星河弃子/蔚蓝之歌/许仙旧事/失忆归巢/尘世独行/尘世偕行/自由开局/其他自定义剧情线名"
      check:
        - 当前剧情线用于驱动剧情路线世界书注入控制器，默认保持命定红瞳
        - 开局选择后应保持稳定，只有玩家明确选择新开局路线或剧情明确切换主线时才允许更新
        - 尘世独行、尘世偕行不注入剧情路线条目，按自由开局处理
    当前时间:
      format: "2012年1月19日/2012年·1月19日·15点45分"
      check:
        - 首次开局必须采用用户提交的开局时间；当前唯一选项为2012年1月19日
        - 每次事件推进、休息或旅行后更新，保持时间流逝合理
    当前地点:
      format: "XX国·XX市·XX地点"
      check:
        - 前端会据此判断通信环境，务必写清具体场所
    当前界域:
      format: "地球/灵域/其他具体界域"
      check:
        - 表示剧情当前实际所处世界或界域；临时提及其他界域时不得更新
    当前国家:
      format: "国家或政治实体正式名称"
      check:
        - 与当前地点保持一致；跨国后立即更新
    当前城市:
      type: |-
        {
          名称: string;
          描述: string;
          状态: string;
          经济: string;
          人口: string | number;
          治安等级: '极佳' | '良好' | '一般' | '较差' | '混乱' | '未知';
          天气: {
            天气状况: string;
            温度: string;
            体感: string;
            特殊现象: string;
          };
        }
      check:
        - 进入新城市时完整 replace 当前城市对象；停留期间只更新发生变化的子字段
        - 描述概括城市定位、风貌与修行界/世俗面的关系，禁止写主角未知的秘密
        - 状态记录正常、戒严、灾害、战乱、灵灾等城市整体状态
        - 经济使用简短等级和说明，如“繁荣—金融与互联网产业发达”
        - 人口采用符合时代和世界书设定的估算，信息不明写未知，不得胡编精确数字
        - 天气必须符合季节、时间与地理；修真异象写入特殊现象
    危机程度: "无/低/中/高/致命"
    动向:
      type: "{ [事件名]: { 类型, 地点, 描述 } }"
      check:
        - 只记录当前地点、当前城市或当前剧情线直接相关的事件；跨国大事写入全球动向，国家级趋势写入国家动向
        - 【滚动栏】每轮必须维持1~8条正在发生的条目。已结束、过时、换地点后不再相关、或被新事件挤掉的旧键必须remove；同一事件仍在发酵则replace原键，禁止另开一条堆历史。禁止只insert不删；写完后清点，少于1条补、多于8条删到8
        - 执行50/50原则：约一半来自客观世界，约一半与主角或当前行动有关
        - 事件必须符合当前年代的时代背景。
        - 事件可以是城市社会新闻、当地异常或修行界传闻
        - 描述需包含起因、当前进展及可能后果，≥50字
    政府动向:
      type: "{ [动向标题]: { 层级, 机构, 地区, 时间, 行动, 描述, 状态 } }"
      check:
        - 层级只能是中央、国家、地方、城市、部门或其他；机构必须使用正式名称
        - 只写具体机构的政策执行、公共安全、灾害响应、调查或行政处置
        - 纯军事部署写军事动向；国家整体趋势写国家动向
        - 【滚动栏】每轮必须维持1~8条。已结束、过时的旧键必须remove；同一行动仍在推进则replace原键。禁止只insert不删，写完后条数必须落在1~8
    军事动向:
      type: "{ [动向标题]: { 国家或势力, 军种, 地区, 时间, 类型, 规模, 描述, 可信度 } }"
      check:
        - 类型只能是部署、调动、演习、冲突、战争、戒备、撤离或其他
        - 可信度只能是传闻、部分证实、已证实
        - 可记录国家军队、军警联合行动或修行势力的大规模武装行动；承平时期写演习、戒备或调动
        - 【滚动栏】每轮必须维持1~8条。已结束、过时的旧键必须remove；同一部署仍在进行则replace原键。禁止只insert不删，写完后条数必须落在1~8
        - 同一军事事件不得同时完整复制到政府动向
    国家动向:
      type: "{ [动向标题]: { 国家, 领域, 时间, 描述, 影响, 趋势 } }"
      check:
        - 领域只能是政治、经济、社会、科技、外交、公共安全、修行界、灾害或其他
        - 记录国家尺度的趋势与重要事件，不写单个部门的具体行动
        - 趋势只能是改善、稳定、恶化、不明
        - 【滚动栏】每轮必须维持1~8条。过时或已被新趋势取代的旧键必须remove；同一趋势仍在发展则replace原键。禁止只insert不删，写完后条数必须落在1~8
    全球动向:
      type: "{ [动向标题]: { 涉及国家或地区, 类型, 时间, 地点, 描述, 全球影响 } }"
      check:
        - 记录跨国、全球或跨界域的重要事件；单一国家内部事件写国家动向
        - 类型只能是国际政治、军事安全、全球经济、科技变革、自然灾害、超凡事件、跨界事件或其他
        - 保持时代真实性，不得用未来平台、未来机构或未发生技术
        - 【滚动栏】每轮必须维持1~8条。过时或已被新事件取代的旧键必须remove；同一事件仍在发酵则replace原键。禁止只insert不删，写完后条数必须落在1~8
    世界局势:
      type: "{ [局势主题]: { 范围, 主题, 态势, 紧张度, 主要参与方, 摘要, 对当前剧情影响, 更新时间 } }"
      check:
        - 世界局势是宏观态势摘要，不是新闻列表；用于回答“世界目前整体往哪里发展”
        - 态势只能是平稳、升温、紧张、冲突、危机、失控、缓和
        - 紧张度为0~100纯数字，只在局势真实变化时调整
        - 摘要应综合多个事件，不得原样复制政府、军事、国家或全球动向
        - 对当前剧情影响只写主角可感知或合理预期的影响，不写隐藏命轨
        - 同时最多6条

  命轨:
    type: "{ [命轨事件标题]: { 时间, 相关人物, 触发条件, 描述 } }"
    check:
      - 【核心定位】命轨是全局剧情埋点触发器，不属于主角属性，也不是向玩家公开未来的预言板
      - 隐藏条件真正满足时才写入；触发条件字段记录可校验的条件摘要
      - 填“马上发生/立刻/即刻/本轮”时，本轮必须执行事件，执行后立即 remove
      - 每个事件只执行一次；失效、冲突或已完成的事件必须移除，最多保留15条

  所处势力:
    type: |-
      {
        [势力全称: string]: {
          类型: '国家政府' | '地方政府' | '军警机构' | '宗门' | '世家' | '企业' | '社会组织' | '地下势力' | '临时团体' | '其他';
          身份: string;
          与主角关系: string;
          势力状态: string;
          势力宗旨: string;
          所在地: string;
          影响力: string;
          势力人数: string;
          势力动向: string;
          关键人物: {
            [人物姓名: string]: {
              身份: string;
              立场: string;
              当前状态: string;
            };
          };
          描述: string;
        };
      }
    check:
      - 势力不局限于宗门，也包括国家政府、军警、世家、企业、社会组织、地下组织和临时团体
      - 主角可以同时属于多个势力，每个势力以正式全称作为键名
      - 身份记录主角在该势力内的职位或资格；主角晋升、降职或伪装身份变化时更新
      - 势力人数用文本描述规模，如「核心十余人、外围数百」
      - 退出、覆灭或关系彻底终止时 remove；若只是敌对但仍有持续组织关系，则更新与主角关系和势力状态

  主角:
    境界:
      format: "大境界小境界（DC:数值）"
      check:
        - 小境界修为满100自动突破并归零；大境界满100时，修为将卡在100不再增加，需要主动突破；
        - "DC总表：凡人0｜炼气1~10（一层1…十层10）｜筑基25~34（初25中28后31圆34）｜金丹49~58（初49中52后55圆58）｜元婴73~82（初73中76后79圆82）｜出窍88~97（初88中91后94圆97）｜化神103~112（初103中106后109圆112）｜炼虚118~127（初118中121后124圆127）｜合体133~142（初133中136后139圆142）｜大乘148~157（初148中151后154圆157）｜渡劫173~182（初173中176后179圆190)"
    ${生命|精血|灵力|神识}:
      type: number
      range: 0~100
    修为:
      type: number
      range: 0~100
      check:
        - 满100触发突破，突破后归零；若遇大境界瓶颈且无条件突破，则锁定在100不再增加
    道心:
      type: number
      range: 0~100
      check:
        - "四境：凡心(0~25) 初窥(26~50) 澄澈(51~75) 磐石(76~100)"
        - 违心/背叛大降，悟道/坚守大升；数值单次增减幅度限制在 ±(2~10) 之间，除非发生极端事件
        - 归零则走火入魔
    神念:
      check:
        - range与强度必须严格匹配当前境界
        - 遭遇隔绝神识的阵法、特殊地形（如迷雾、禁地）、或高阶修士灵压时，必须更新状态并描述受限情况
        - 强行探测被反噬或受到灵魂/神识攻击时，更新状态为“受损描述”，并必须联动扣除【主角.神识】数值
        - 探测结果需记录当前神念扫描到的隐秘地形、埋伏的敌人、异宝波动或阵法结界；若未开启探测或无异常则填“无发现”
    气运:
      type: "{ [气运名]: { 类型:'被动'|'主动', 效果, 使用状态:'常驻'|'可用'|'冷却中'|'已耗尽', 剩余次数, 压制状态:'正常'|'被压制' } }"
      check:
        - 开局固定获取，之后不再新增
        - 气运被动使用或主动使用时更新使用状态 and 次数
        - 对自身DC远差对方30时使用气运，需要更新压制状态为被压制，解除危机或放弃使用时可恢复更新压制状态为正常
    灵根:
      check:
        - 开局确定，一般不变
        - 仅在洗髓、夺灵根、天降造化等极端事件下才可能变化
    身份:
      check:
        - 记录主角当前对外使用的主要社会身份或职业，如大学生、军人、公司职员、散修
        - 势力内职位不得混写于此，应写入所处势力.{势力名}.身份
    状态:
      check:
        - 短摘要，如中毒、受伤、封印、完全失忆，顿号分隔；无则写无异常
        - 只给战斗 HUD 和一句话总览；结构化细节必须写 异常状态，不要把长说明塞进这串
        - 部分解除时只改摘要，直到全部解除才写回无异常
        - 失忆归巢开局必须含完全失忆，禁止开局恢复记忆
    异常状态:
      type: "{ [状态名]: { 说明, 程度, 进度, 持续 } }"
      check:
        - 自由对象，键名即状态名。禁止枚举、禁止白名单。正文里出现的异常按剧情自拟中英文名均可
        - 每条必须含 说明、程度(0~100)、进度(0~100)、持续。说明写成因与当下表现；程度写当前强度；进度写走向终结或恶化的百分比（0刚起、100将解或将成）；持续写时限、未愈、永久等
        - 新状态 insert 整条；加深/消退 replace 子字段或整条；解除必须 remove 该键，禁止留空对象。无异常保持 {}
        - 部位观感仍写 身体状态；心理定位写自我认知；这里只记会改变行动能力或心智的异常
        - 禁止再写 堕落值。原堕落、心智崩坏、污染等一律改成一条自拟名的异常状态
        - 失忆归巢开局必须 insert /主角/异常状态/完全失忆，程度高、进度低、持续未愈
    衣着:
      type: "{ 上装, 下装, 内衣, 内裤, 袜子, 鞋子, 配饰 }"
      check:
        - 与当前在场角色衣着同一套七字段，缺一不可
        - 每项写 [品牌 颜色 款式]，品牌按主角阶层与身份推演，禁止无脑杂牌
        - 修仙者可写法衣、道袍、护甲品阶；凡俗按职业与季节写常服
        - 开局必须写入一套完整着装；换装、湿透、破损、褪去、披上外套时逐项刷新
        - 只换一件也只改对应子字段，例如 /主角/衣着/上装
        - 【防崩警告】禁止对整个 衣着 对象 replace，除非开局首次写入，或因性别转换导致字段集变化
    身体状态:

        {
          面容: string;
          胸腹: string;
          腰臀: string;
          性器: string;
          后庭: string;
          手足: string;
